# Production rollout
Vercel production build runs the CEO contract tests, generates the Prisma client and executes only scripts/sql/grok-ceo-exchange.sql and scripts/sql/business-expense-candidate.sql as one transaction, against its existing DATABASE_URL. The script runs only with VERCEL_ENV=production. Preview and local builds skip DDL. It is idempotent, does not query or modify historical business or patient records, and never executes a full schema push. If migration fails, the production build fails before replacing the deployment. No secret is printed.
The advisory channel and expense ingestion remain disabled until dedicated credentials are securely provisioned and corresponding external sources configured; neither existing Grok token gains permissions. Weekly strategy can be sent as an optional Monday field without changing the existing routine. Verify authenticated screens and synthetic integration on a test environment before enabling connectors.
